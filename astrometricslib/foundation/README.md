# Foundation

This folder holds the infrastructure that both libraries, the backend, the MCP servers and the scripts all share, so none of them has to own it. The code here imports nothing else from `astrometricslib`, `wayfindinglib` or the backend. Other code imports its names from the top-level `astrometricslib` package.

Terms are defined in the [glossary](../../documentation/Glossary.md). This document also defines each term the first time it appears.

## What each file is for

- `errors.py` — one family of errors for the libraries, the backend and AI agents, and the `ErrorInfo` record that carries an error over JSON. Each error category says what kind of problem happened and what the caller can do about it.
- `logging.py` — one way to set up logging, a log context that tags every message with the call or job that wrote it, and the router that fills a job's own log.
- `config.py`, `config_schema.py` — the application configuration loader, and the Pydantic models (typed, validated classes) that define the configuration's structure and defaults. A save writes a temporary file and moves it over the config (`os.replace`), under a write lock (`AppConfiguration.write_lock`, a thread lock and a lock file beside the config), so a crash or a second writer never leaves a half-written file.
- `observatory_setups.py`, `observatory_site.py` — read the optics (telescopes and lenses), the camera-and-optic setups and the observatory's location from the config file. The site reader has no default site, because a made-up site would give wrong time corrections.
- `launch_identity.py` — reads the optional, read-only `[Launch]` section of the settings file. A program that starts the app (a launcher) writes it to say what kind of run this is: `label` (text for the status chip), `live_hardware`, `disposable_library`, `offline` and `locked_keys` (the `Section.key` names the settings page cannot change). `LaunchIdentity` holds the answer, and `AppConfiguration.get_launch_identity` returns it, or `None` for an ordinary run. This module is the one place that parses the section. Nothing in the libraries builds or removes anything from it.
- `source_choice.py` — the one copy of the observatory source choice: the saved "real or simulated" answer (`observatory_source.json` in the settings folder), the functions that read and write it, the exit code `RESTART_EXIT_CODE` (75) the app ends with when the user changes it, and the names of the environment variables a launcher sets. A launcher reads the choice before it starts the app; the app only reports it and saves a new one. Public through `astrometricslib.drivers`.
- `offline.py` — the choke point for outgoing network clients. When the launch says `offline = true`, `require_online` (an internet service) and `require_local_host` (a telescope computer reached by host name) raise `OfflineModeError`, a `ConnectionError`. The code that already handles an unreachable service therefore treats it as unavailable: a status, not an error. Loopback hosts (`localhost`, `127.x.x.x`, `::1`) stay allowed, because the simulator's stand-ins listen there. The clients that call it are SIMBAD, the Gaia cone and reddening queries, Gaia XP downloads, the online plate solver, SkyBoT, the CDS cross-match, the deep star catalog download, the SIMBAD name and region lookups, the ssh, rsync, INDI and PHD2 links to a telescope computer, and the Drive scripts.
- `camera_names.py` — turns the several spellings of one camera name (FITS header, config file, frame record) into one form so they can be compared.
- `enums.py` — enumerations (fixed sets of named values) shared by the domain models.
- `constants.py` — numbers that several packages share and that have no better home. It holds `FULL_SCALE_COUNTS`, the stack value of a full 16-bit pixel.
- `paths.py` — names the folders for temporary working files on the local disk, and treats the two Linux spellings of a mounted-drive path as the same place. `library_folders(config_file)` reads the library, frames, stacks and wayfinding folders that any one settings file names, and `real_folders` finds the user's real ones through the environment.
- `astropy_setup.py` — makes astropy use its bundled Earth-rotation (IERS) table offline and loads that table ahead of first use, so a coordinate conversion never waits on a download.
- `run_abandonment.py` — lets a run that was given up on stop its own helper programs. The code that starts a run (a stack in a background thread) makes a `RunAbandonment` and binds it for that thread. Code that starts a helper program, such as Siril, registers it through `launch_registered`. When the caller gives up, `abandon` stops the process groups of that run's programs only (nothing is found by name) and later starts are refused, so the thread ends and gives its job slot back. `raise_if_abandoned` is the check that code on that thread uses to stop before it records anything. `run_registered` runs a program to the end in a process group of its own, with or without a bound run, and `stop_process_group` ends a program and every helper it started; a timeout in `run_registered` uses it. GraXpert, Cosmic Clarity, the preview's Siril and `solve-field` all run through `run_registered`. `stop_process_group` is also exported from `astrometricslib.drivers` for `wayfindinglib`.
- `run_tally.py` — a running total that belongs to one run (the seconds a stack waited for a free Siril slot, the tries a plate solve needed), not to the process. The code that starts the run makes a `RunTally`, binds it for its thread with `bind_tally`, and reads it back; the deep code adds to whichever tally is bound there and does nothing when none is. A thread the run starts binds the tally itself.
- `versioned_cache.py` — `VersionedCache`, the one cache for slow results. It keeps each result with the data version it was built from (see `storage/data_versions.py`) and gives it back only while that version is unchanged. It is thread safe, drops the result used longest ago when full, makes one thread build a missing result while the others wait, hands each caller its own copy, and keeps nothing when the version is unknown (`None`). Night reviews, target reports, depth goal statuses, sky models, the star overlay and the dark and bias health of `processing.calibration.assess` each hold one. It is public through `astrometricslib.drivers`.
- `warn_once.py` — logs a given warning only once per run, so one config mistake met on every frame does not bury other messages.
- `jobs/` — the job framework. See [jobs/README.md](jobs/README.md).
- `storage/` — generic storage plumbing. See [storage/README.md](storage/README.md).

For exact behavior, read the code.
